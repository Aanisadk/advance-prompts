# Contributing

Thanks for helping improve ADVANCE-PROMPTS!

1. Choose a category folder under `prompts/`.
2. Add a unique ID, title, category, platform, difficulty, description, prompt, variables, usage, and review date.
3. Update the category JSON, master catalogue, and package data.
4. Submit original or appropriately licensed content.
5. Explain every variable and include useful usage guidance.
6. Run `python -m pytest` and validate JSON before opening a pull request.

Prompts should be specific, reusable, meaningfully distinct, and honest about uncertainty. Never add secrets, personal data, confidential content, or harmful instructions. For model-specific advice, link official docs and include a review date.
